Rane SL3 CoreAudio Driver

Nativo para Apple Silicon (M1 / M2 / M3 / M4) & Intel

Idea original y proyecto por: pepelee (PPLEE)
Instagram: @pepeleedj — instagram.com/pepeleedj/

Este instalador configurará en tu Mac el driver de baja latencia para la tarjeta de sonido Rane SL3:

  • 6 Entradas y 6 Salidas (Aux, Left Deck y Right Deck) a 24-bit / 44.1 o 48 kHz, con motor de audio de baja latencia.
  • Conmutación automática USB / Thru al abrir y cerrar tu software de audio (Ableton Live, Traktor, Mixxx, Serato, Logic Pro, etc.).
  • App SL 3 Control Panel (en Aplicaciones) y utilidad sl3panel: selector Phono/Line de cada plato, Thru, sensibilidad phono, volumen y niveles.
  • Serato DJ Pro 2.5.5: incluye Sl3Api.framework (modos DVS ABS / REL / INT y THRU).
  • Activación inmediata: No requiere reiniciar el ordenador ni desactivar la seguridad del sistema (SIP).
